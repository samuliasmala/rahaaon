# Rahaa on.

Rahaaon.fi — kansalaisten ilmoittamia, tekoälyn tiivistämiä ja toimituksen tarkistamia julkisen rahankäytön rahareikiä.

A crowdsourced tracker of wasteful public spending in Finland: citizens submit a link to a news
article, an AI pass extracts the amount, entity and category and drafts a summary, and an editorial
queue reviews everything before it is published to the public feed.

## Stack

pnpm + Turborepo monorepo, TypeScript (strict, ESM).

- `apps/web` — React 19 SPA: Vite, TanStack Router (file-based) + TanStack Query, Tailwind CSS v4
  (CSS-first theme), better-auth client, sonner. The API client under `src/api/` is generated by
  orval from the API's OpenAPI document. UI text is Finnish.
- `apps/api` — Hono + `@hono/zod-openapi` REST API: Drizzle ORM on PostgreSQL 17, better-auth
  (email/password, sign-up disabled — editorial accounts only), pino logging, tsdown build.
  Swagger UI at `/api/docs`.

Anonymous readers browse the feed, vote ("tämä on turhaa", one vote per visitor cookie, toggle to
retract) and submit article links. The AI extraction (`apps/api/src/lib/suggestion-ai.ts`) is still
a mock — swap `extractArticle` for a real LLM pipeline without touching routes or UI.

## Development

```bash
pnpm install
docker compose up -d          # Postgres 17 on :5434
cp .env.example .env
pnpm db:migrate
pnpm db:seed                  # demo content + editor login (toimitus@rahaaon.fi / rahaaon-dev)
pnpm dev                      # web on :5174, api on :3001 (vesi owns 5173/3000)
```

Checks: `pnpm lint`, `pnpm typecheck`, `pnpm test` (includes API integration tests against an
ephemeral Postgres via testcontainers), `pnpm build`.

After changing API routes/schemas, regenerate the web client:

```bash
pnpm --filter @rahaaon/api openapi:export
pnpm --filter @rahaaon/web api:generate
```

## Design

The UI implements `docs/design/rahaaon-proto.dc.html` (Claude Design project
"Rahaaon.fi turhien menojen keruu"). Design tokens (colors, fonts) are defined in
`apps/web/src/styles/globals.css`.
